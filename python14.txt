Лабораторная работа

Шифрование и расшифрование текста с использованием матрицы

Цель работы

В данной лабораторной работе я реализовал собственный простой алгоритм шифрования текста на языке Python. В основе алгоритма используется матричное преобразование и арифметика по модулю.

Моя задача заключалась в том, чтобы преобразовать обычный текст в зашифрованный вид, а затем с помощью обратного преобразования получить исходный текст обратно.


1. Принцип работы алгоритма

Для работы программы я использовал английский алфавит из 26 букв:

abcdefghijklmnopqrstuvwxyz

Каждой букве соответствует число от 0 до 25:

a = 0
b = 1
c = 2
...
z = 25

Это необходимо для того, чтобы с буквами можно было выполнять математические операции.

В качестве ключа шифрования я использовал матрицу:

3  2
1  1

Текст обрабатывается по две буквы. Каждая пара букв сначала переводится в два числа.

Например, для пары "he":

h = 7
e = 4

Получается набор из двух чисел: 7 и 4.

Далее эти два числа рассматриваются как вектор и умножаются на матрицу.

Для получения первого числа используется первая строка матрицы:

3 * x1 + 2 * x2

Для второго числа используется вторая строка:

1 * x1 + 1 * x2

После этого от результата берётся остаток от деления на 26. Это необходимо, потому что в нашем алфавите только 26 символов.

2. Подготовка текста

Сначала программа создаёт строку с алфавитом:

alphabet = "abcdefghijklmnopqrstuvwxyz"

Затем пользователь вводит текст:

text = input("Введите текст: ").lower()

Функция lower() переводит все введённые буквы в нижний регистр.

После этого программа удаляет пробелы:

text = text.replace(" ", "")

Я сделал это для того, чтобы программа работала только с буквами и не требовала отдельного математического преобразования для пробела.


3. Работа с нечётным количеством символов

Так как алгоритм работает с двумя символами одновременно, количество символов должно быть чётным.

Для проверки используется:

if len(text) % 2 != 0:

Если количество символов нечётное, программа добавляет в конец букву x:

text += "x"

Например, если пользователь ввёл:

hello

В слове 5 букв, поэтому программа преобразует его в:

hellox

Теперь количество символов равно 6, и текст можно разделить на пары:

he
ll
ox

Буква x в данном случае является просто дополнительным символом для заполнения последней пары.



4. Разделение текста на пары

Для обработки текста используется цикл:

for i in range(0, len(text), 2):

Число 2 означает, что на каждой итерации мы переходим сразу к следующей паре символов.

Например:

hello -> hellox

После разделения получаем:

he
ll
ox

Для каждой пары программа отдельно выполняет математическое преобразование.



5. Перевод букв в числа

Следующий блок получает числовое значение каждой буквы:

x1 = alphabet.index(text[i])
x2 = alphabet.index(text[i + 1])

Функция index() ищет положение символа в строке alphabet.

Например:

h имеет индекс 7
e имеет индекс 4

Поэтому для пары "he":

x1 = 7
x2 = 4


6. Матричное преобразование

Основная часть алгоритма находится в двух строках:

y1 = (matrix[0][0] * x1 + matrix[0][1] * x2) % 26

y2 = (matrix[1][0] * x1 + matrix[1][1] * x2) % 26

Здесь используется матрица:

3  2
1  1

Первая строка матрицы используется для получения первого нового числа:

y1 = 3 * x1 + 2 * x2

Вторая строка используется для получения второго числа:

y2 = 1 * x1 + 1 * x2

После вычисления используется % 26.

Оператор % получает остаток от деления числа на 26.

Например:

29 % 26 = 3

Это позволяет всегда получать число от 0 до 25, которое можно сопоставить с буквой нашего алфавита.



7. Пример шифрования

Рассмотрим пару "he".

Сначала переводим буквы в числа:

h = 7
e = 4

Используем первую строку матрицы:

3 * 7 + 2 * 4 = 29

После взятия остатка:

29 % 26 = 3

Числу 3 соответствует буква d.

Теперь используем вторую строку:

1 * 7 + 1 * 4 = 11

Числу 11 соответствует буква l.

Таким образом:

he -> dl

То же самое программа выполняет для всех остальных пар текста.



8. Получение зашифрованного текста

После получения новых чисел программа снова переводит их в буквы:

encrypted += alphabet[y1] + alphabet[y2]

Таким образом, числовые результаты преобразования объединяются в одну строку.

В конце программа выводит:

print("Зашифрованный текст:", encrypted)

Например:

hello

после добавления символа для выравнивания:

hellox

После обработки пар:

he -> dl
ll -> dx
ox -> kl

Получаем зашифрованный текст:

dldxkl



9. Расшифрование

Для расшифрования используется отдельная программа.

Главная идея заключается в том, что матричное преобразование можно выполнить в обратную сторону.

Для этого вместо исходной матрицы используется обратная матрица:

1  24
25  3

Она была получена из исходной матрицы с использованием математических операций с матрицами и арифметики по модулю 26.

Программа снова разделяет зашифрованный текст на пары символов и переводит их в числа.

Например:

dl

d = 3
l = 11

После этого числа умножаются уже на обратную матрицу.

Получается исходная пара:

h = 7
e = 4

После перевода чисел обратно в буквы получаем:

he

Таким образом, весь зашифрованный текст можно вернуть к исходному виду.



10. Почему расшифрование работает

Для расшифрования важным является то, что исходная матрица имеет обратную матрицу.

Исходная матрица:

3  2
1  1

Её определитель равен:

3 * 1 - 2 * 1 = 1

Так как определитель равен 1, он имеет обратный элемент по модулю 26. Поэтому для этой матрицы можно построить обратное преобразование.

Если сначала применить исходную матрицу, а затем обратную, исходные значения возвращаются обратно.

Именно поэтому зашифрованный текст можно расшифровать.


11. Итог

В результате лабораторной работы я реализовал собственный алгоритм шифрования текста на Python.

В алгоритме используются математические операции с матрицами, преобразование букв в числовые значения и арифметика по модулю 26.

Главная особенность алгоритма заключается в том, что две соседние буквы обрабатываются одновременно. Благодаря этому шифрование отличается от обычного посимвольного сдвига.

Также я реализовал обратное преобразование, поэтому полученный зашифрованный текст можно расшифровать и восстановить исходное сообщение.
